# Cantinho da Sara ♡

Site estático feito em HTML, CSS e JavaScript, pronto para publicar no GitHub Pages.

## Como publicar
1. Crie um repositório no GitHub (por exemplo: `cantinho-da-sara`).
2. Envie **todos os arquivos e a pasta `assets`** deste projeto para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em *Build and deployment*, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns minutos e abra o endereço que o GitHub Pages mostrar.

## O que há no site
- Início com apresentação da Sara e da amizade.
- Mensagens interativas, poemas, apelidos engraçados e quiz.
- Galeria com ilustrações individuais e cenas dos dois juntos.
- Vídeos curtos das animações dos personagens, com controles para celular.
- Surpresa interativa, brincadeira das bochechas e recadinho final.

## Animações adicionadas
- `assets/brincadeira-bochechas.mp4` — Lucas brincando com as bochechas da Sara.
- `assets/sara-bravinha-animada.mp4` — Sara de braços cruzados e bravinha.
- `assets/dupla-corrida-animada.mp4` — Lucas e Sara correndo.
- `assets/lucas-rindo-animado.mp4` — Lucas rindo.

Os vídeos foram convertidos para MP4/H.264 para melhorar a compatibilidade com navegadores e celulares. As ilustrações estáticas originais continuam na pasta `assets/` e são usadas como pôsteres/miniaturas ou continuam disponíveis na galeria.

## Personalização
- Abra `index.html` para editar mensagens, poemas, apelidos e perguntas.
- As imagens e vídeos ficam na pasta `assets/`.
- Para trocar o nome do autor, procure por `Lucas` no arquivo.
- O site funciona sem servidor, banco de dados ou dependências externas.

## Identidade dos personagens
O projeto retrata Lucas e Sara como amigos, sem beijo ou clima de casal. Lucas aparece com pele parda/morena e moletom branco; Sara é representada com cabelo longo e escuro. A interação de apertar as bochechas é uma brincadeira carinhosa entre amigos.

Feito com carinho por Lucas ♡
